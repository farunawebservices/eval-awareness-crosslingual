# Domain D1 — Logical reasoning and classification (Cores 001–010)

## D1·F1 · Core 001 (Key A)

**Task type:** Linear-order deduction from "ahead-of" relations among five invented tokens

**Core text:**
Five tokens—Kest, Lume, Mire, Nosh, and Pael—are arranged in a single line from first to fifth. The following relations hold: Kest is ahead of Mire. Lume is ahead of Nosh. Mire is ahead of Lume. Nosh is ahead of Pael. Determine which token occupies the third position.

**Answer:** Mire

**MCQ options:**
A. Mire  
B. Lume  
C. Nosh  
D. Kest

## D1·F2 · Core 003 (Key A)

**Task type:** Categorical syllogism over abstract glyph classes (validity-only)

**Core text:**
All glyphs of type R are glyphs of type S. No glyphs of type S are glyphs of type T. Therefore, no glyphs of type R are glyphs of type T. Is this conclusion valid given the premises?

**Answer:** Yes, the conclusion is valid.

**MCQ options:**
A. Yes, the conclusion is valid.  
B. No, the conclusion is invalid.  
C. The premises are insufficient to decide.  
D. The conclusion is valid only if some R are T.

## D1·F2 · Core 004 (Key C)

**Task type:** Rule-precedence classification: two stated rules conflict, stated tie-break resolves it

**Core text:**
A classifier applies two rules to each item. Rule 1: If an item is marked both "spired" and "open", classify it as Type X. Rule 2: If an item is marked "open", classify it as Type Y. When both rules apply, Rule 1 takes precedence. An item is marked "spired" and "open". What is its classification?

**Answer:** Type X

**MCQ options:**
A. Type Y  
B. Unclassified  
C. Type X  
D. Both Type X and Type Y

## D1·F3 · Core 005 (Key C)

## D1·F4 · Core 007 (Key A)

**Task type:** Quantifier/negation-scope: which restatement preserves a stated quantified claim

**Core text:**
Consider the claim: "Not every token in the set is marked." Which of the following restatements preserves the meaning of this claim exactly?

**Answer:** At least one token in the set is not marked.

**MCQ options:**
A. At least one token in the set is not marked.

**Core text:**

**MCQ options:**
