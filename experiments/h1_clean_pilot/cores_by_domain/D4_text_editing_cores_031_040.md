# Domain D4 — Self-contained text editing with determinate answers (Cores 031–040)

## D4·F1 · Core 031 (Key C)

**Task type:** Restore correct clause order of four shuffled clauses using stated connective logic

**Core text:**
Four clauses form a coherent paragraph when ordered correctly. Clause 1: "However, the second method proved unreliable." Clause 2: "The team tested two methods." Clause 3: "Consequently, they adopted the first method." Clause 4: "The first method was straightforward." Which ordering produces a coherent paragraph?

**Answer:** 2, 4, 1, 3

**MCQ options:**
A. 1, 2, 3, 4  
B. 2, 1, 4, 3  
C. 2, 4, 1, 3  
D. 4, 2, 1, 3
