# Domain D6 — Fictional-passage reading comprehension (Cores 051–060)

## D6·F1 · Core 051 (Key A)

**Task type:** Explicit detail retrieval from a short invented-setting passage

**Core text:**
Passage: In Orvel Hollow, grain arrives by cart each morning and by handbarrow each afternoon. Handbarrow loads are weighed at the gate and again at the loft. A disputed cart load is settled by the driver's tally cord; a disputed handbarrow load is settled by the loft weighing. According to the passage, how does grain arrive in the afternoon?

**Answer:** By handbarrow

**MCQ options:**
A. By handbarrow  
B. By cart  
C. By wagon  
D. By sled

## D6·F1 · Core 052 (Key C)

**Task type:** Count of a passage-mentioned item class derived from stated sentences

**Core text:**
Passage: The Kest workshop has three tools: a polisher, a sander, and a glue gun. The Lume workshop has four tools: a polisher, a sander, a cutter, and a press. How many tools are mentioned in total across both workshops?

**Answer:** 7

**MCQ options:**
A. 5  
B. 6  
C. 7  
D. 8

## D6·F2 · Core 053 (Key C)

**Task type:** Chronological reordering of events narrated out of order

**Core text:**
Passage: The team calibrated the device. Before calibration, they had installed the processor. After calibration, they ran a test. The test failed, so they recalibrated. In what order did these events occur?

**Answer:** Install processor, calibrate, run test, recalibrate

**MCQ options:**
A. Calibrate, install processor, run test, recalibrate  
B. Install processor, run test, calibrate, recalibrate  
C. Install processor, calibrate, run test, recalibrate  
D. Run test, install processor, calibrate, recalibrate

---

## D6·F2 · Core 054 (Key D)

**Task type:** Which listed claim is *not* supported by the passage

**Core text:**
Passage: All Vex devices require calibration before use. Wex devices do not require calibration. Both Vex and Wex devices must be stored in a dry environment. Which claim is not supported by this passage?

**Answer:** Wex devices require calibration before use.

**MCQ options:**
A. All Vex devices require calibration before use.  
B. Wex devices do not require calibration.  
C. Both Vex and Wex devices must be stored in a dry environment.  
D. Wex devices require calibration before use.

## D6·F3 · Core 055 (Key A)

**Task type:** Meaning-in-context of an invented term defined implicitly by the passage

**Core text:**
Passage: In the Kest system, a "spired" token is one that has been marked with a vertical line. An "open" token is one that has been marked with a circle. A token can be both spired and open. What does "spired" mean in this passage?

**Answer:** Marked with a vertical line

**MCQ options:**
A. Marked with a vertical line  
B. Marked with a circle  
C. Marked with both a line and a circle  
D. Unmarked

---

## D6·F3 · Core 056 (Key B)

**Task type:** Central-tension / main-point identification for the passage

**Core text:**
Passage: The team faced a choice: use the faster Kest processor, which was less reliable, or the slower Lume processor, which was more reliable. They chose the Lume processor because reliability mattered more than speed for this task. What is the main point of this passage?

**Answer:** Reliability was prioritized over speed in the processor choice.

**MCQ options:**
A. The Kest processor is faster than the Lume processor.  
B. Reliability was prioritized over speed in the processor choice.  
C. The Lume processor is slower than the Kest processor.  
D. The team made a mistake in choosing the processor.

## D6·F4 · Core 057 (Key A)

**Task type:** Motive inference supported by exactly one explicit textual cue

**Core text:**
Passage: The technician recalibrated the device. The log states: "Recalibration was performed because the initial calibration drifted beyond acceptable tolerance." Why did the technician recalibrate?

**Answer:** The initial calibration drifted beyond acceptable tolerance.

**MCQ options:**
A. The initial calibration drifted beyond acceptable tolerance.  
B. The device was broken.  
C. The technician wanted to test the device.  
D. The log required a recalibration entry.

---

## D6·F4 · Core 058 (Key C)

**Task type:** Causal chain: which stated event directly caused the stated outcome

**Core text:**
Passage: The test failed because the device was not calibrated. The device was not calibrated because the technician forgot. The technician forgot because the reminder alert was disabled. What directly caused the test to fail?

**Answer:** The device was not calibrated.

**MCQ options:**
A. The technician forgot.  
B. The reminder alert was disabled.  
C. The device was not calibrated.  
D. The test was too difficult.

---

## D6·F5 · Core 059 (Key B)

**Task type:** Belief attribution: which character holds a stated belief

**Core text:**
Passage: Technician Vex said: "The Kest processor is faster." Technician Wex said: "The Lume processor is more reliable." Which technician believes the Kest processor is faster?

**Answer:** Technician Vex

**MCQ options:**
A. Technician Wex  
B. Technician Vex  
C. Both technicians  
D. Neither technician

---

## D6·F5 · Core 060 (Key D)

**Task type:** Contradiction spotting between two characters' quoted statements

**Core text:**
Passage: Technician Vex said: "All Vex devices are calibrated at the factory." Technician Wex said: "Some Vex devices are not calibrated at the factory." What is the relationship between these two statements?

**Answer:** They contradict each other.

**MCQ options:**
A. They are both true.  
B. They are both false.  
C. They are consistent with each other.  
D. They contradict each other.
