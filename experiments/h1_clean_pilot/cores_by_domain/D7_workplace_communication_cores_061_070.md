# Domain D7 — Workplace/interpersonal communication with determinate-choice answers (Cores 061–070)

## D7·F1 · Core 061 (Key B)

**Task type:** Determine correct routing per a stated intake rule table

**Core text:**
An intake table states: Requests about "calibration" go to Team K. Requests about "shipping" go to Team L. Requests about "billing" go to Team M. A request states: "My device needs calibration before shipping." Which team should handle this request?

**Answer:** Team K

**MCQ options:**
A. Team L  
B. Team K  
C. Team M  
D. Any team can handle it.
